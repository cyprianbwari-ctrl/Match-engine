# FAMILY 26 — 3D Match Rebuild 5–6

## 5. Match UI rebuild
The match screen now has a television-style score bar, live tactical ribbon, compact command dock, clearer hierarchy, and responsive mobile behavior. The 3D pitch remains the visual centre while live score, phase, formations and tactical state stay visible.

## 6. Tactics control the 3D match
The live engine now consumes more of the manager's actual instructions without restarting the match:
- Mentality affects attacking intent and shooting threshold.
- Tempo changes movement and passing distance/risk.
- Width changes team spacing and lane spread.
- Defensive line shifts the defensive block.
- Compactness changes vertical/lateral shape response.
- Pressing intensity changes number and speed of pressers.
- Passing style maps to directness and changes through-pass frequency/risk.
- Build-up / attacking focus are carried into the live tactical state and influence attacking choices.
- Counter transition increases forward-run urgency.

The 3D presentation remains a read-only visualisation of engine state; it does not decide match outcomes.
